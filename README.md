# EHOU K23 - Ứng Dụng Tạo Tập Luyện Chữ Hán

Công cụ hỗ trợ tạo file PDF luyện viết chữ Hán thông minh dành riêng cho sinh viên Khoa Tiếng Trung - EHOU K23.
Hệ thống tự động tra cứu Pinyin, nghĩa Hán Việt, và hướng dẫn từng nét vẽ (Stroke order) một cách chính xác.

Ứng dụng giúp tiết kiệm thời gian, tự động lọc chữ trùng lặp và bỏ qua các chữ quá cơ bản.

- Phát triển bởi: Andrew Tseng
- Nền tảng: Streamlit Cloud
- Định dạng xuất: PDF chuẩn A4 (Layout Mễ Tự Cách - 米字格)
